# 🎌 Anikuro (アニクロ) - Deliverables & Source Directory

This directory contains the production-ready packages and source code for the **Anikuro** Anime Tracking & AI Oracle platform:

---

## 📁 Packages Overview

### 1. 🌐 Web Application (Ready-to-Host & Direct Open)
- **Folder**: `AniKuro Web App/`
- **Zip Archive**: `AniKuro-Web-App.zip` (4.55 MB)
- **Features**:
  - **Direct Open**: Double-click `index.html` in Windows Explorer to use the app immediately offline.
  - **Online Hosting**: Drag and drop `AniKuro-Web-App.zip` or the `AniKuro Web App/` folder into [Netlify Drop](https://app.netlify.com/drop) or Vercel for free custom HTTPS hosting.
  - **AniList OAuth2**: Connect and authorize your AniList profile with 1 click to fetch your entire watch history.

---

### 2. 📱 Mobile Application (Android Studio Project)
- **Folder**: `AniKuro Mobile App/`
- **Zip Archive**: `AniKuro-Mobile-App.zip` (16.2 MB)
- **Features**:
  - Open in **Android Studio** (`File ➔ Open` ➔ `D:\AniKuro\AniKuro Mobile App`).
  - Synced with Java 21 LTS & Gradle 8.13.
  - Build `.apk` anytime via `Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)`.
